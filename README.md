# Drzewo BST w C++

Implementacja drzewa binarnego poszukiwań (BST) w języku C++.

## Opis

Program tworzy drzewo binarne poszukiwań i umożliwia dodawanie elementów oraz wypisywanie ich w kolejności rosnącej.

W projekcie wykorzystano:
- strukturę `wezel` reprezentującą pojedynczy węzeł,
- klasę `drzewo` zarządzającą drzewem,
- rekurencję,
- wskaźniki,
- konstruktor i destruktor.

## Funkcjonalności

- Dodawanie elementów do drzewa.
- Wstawianie elementów zgodnie z zasadami BST.
- Wypisywanie drzewa metodą in-order.
- Automatyczne usuwanie wszystkich węzłów przy zakończeniu programu.
